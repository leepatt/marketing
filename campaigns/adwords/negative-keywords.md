# Negative keywords — Craftons AdWords

_Add at **campaign level** so all 3 ad groups inherit them. Add as **phrase-match** negatives
(single words then block any query containing that word). Review the Search Terms report weekly and
keep adding. Remove any that you find are blocking real buyers._

## Why these matter most
"Curved plywood / bendy ply" attracts a lot of **hobbyists** — skateboard, guitar, furniture and
model makers — who'll never buy building products. Plus the usual **DIY / free / jobs / hire /
research** clicks. These are where a $50/day budget bleeds. The list below kills that traffic.

## Notes
- **Hobby terms** (skateboard, guitar, furniture, chair, boat…) are the big savers for the Radius Pro
  group — that's who searches "bendy ply" without buying building products.
- **hire / rent / rental / lease** — important for the Formwork group: we *sell* kits, we don't hire.
- Keep the list growing from the weekly **Search Terms report** — that's where new waste shows up.
