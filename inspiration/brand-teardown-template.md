## 8. Research sources (where to pull each)

| Source | Gives you | Cost |
|---|---|---|
| IG / TikTok / YT / LinkedIn direct | Content, cadence, engagement | Free (IG partly login-walled → screenshots to `_inspo-dump/`) |
| Meta Ad Library | Every active Meta ad in a region + run dates | Free web UI |
| Google Ads Transparency Center | Active Google/YouTube ads | Free |
| TikTok Creative Center / LinkedIn Ad Library | Active ads on those platforms | Free |
| Social Blade | Follower growth history | Free |
| SimilarWeb | Website traffic + sources | Free tier |
| Ahrefs / SEMrush / SpyFu | Organic + paid keywords, est. spend | Paid |
| Their newsletter | Email cadence, offers, funnel | Free (subscribe) |

> **Note on ad APIs:** the Meta Ad Library API is restricted for general commercial ads, and Google's Transparency Center has no clean public API — so the practical route is the **web UIs** (scrape via Firecrawl once keyed, or screenshot into `_inspo-dump/`), not the official APIs.
