# Craftons Design — skill

This skill makes Claude design and write **on-brand** for Craftons. The full, canonical
design system (exact token CSS, licensed fonts, logos, pattern PNGs, product photography, the
UI kit, and the source brand-guidelines PDF) lives in the **Google Drive brain**, not in this
repo — it is too large/binary to commit. This skill carries the **rules** and tells you how to
pull the **exact assets** when you need them.

## Read these first
- `BRAND.md` — the brand rules: palette, type, voice, casing, the motif, component conventions.
  Internalise this before writing or designing anything.
- `SOURCE.md` — the canonical design-system location in Drive (folder + per-file IDs) and how to
  fetch the exact `colors_and_type.css` tokens, fonts, and assets via the Google Drive connector.

## How to use it

**Producing a visual asset (social graphic, ad, carousel, slide, mock):**
1. Read `BRAND.md` so the palette, type, motif, and rules are loaded.
2. Pull the exact tokens — fetch `colors_and_type.css` from Drive (`SOURCE.md` has the file ID),
   `@import` it at the top of the HTML, and add `class="craftons"` to `<body>` to inherit defaults.
3. Pull only the assets you need (logo, a pattern PNG, a product shot) from the Drive `assets/`
   and `fonts/` folders — don't inline guesses.
4. Build as an **HTML artifact** using design-system tokens via `var(--token)` — never raw hex or
   raw px (the system's lint rules forbid it; off-system fonts are flagged too).
5. Render to the final image/video format with the media scaffold (B9: headless-browser render +
   sharp/ffmpeg) at the right dimensions (e.g. 1080×1350 IG portrait).

**Writing copy:** apply the voice rules in `BRAND.md` — builder-to-builder, short, period-terminated.

## Hard rules (never break)
- Palette is **deep forest green `#194431` + black + warm off-white**. No gradients on UI. No emoji.
- Type: **Aeonik** (display) + **Inter** (body) + **Anton / HWT Artz** (compliance stamps only).
- The **curved-line motif** is the signature — big, once per page, behind hero text.
- **ALL CAPS is reserved for compliance/spec callouts only**, always in a condensed/stencil face.
- Buttons are square-ish (~6px radius), dark green.
