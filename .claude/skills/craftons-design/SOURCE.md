# Canonical design system — source & how to fetch

The **full Craftons Design System** is canonical in the Google Drive brain. This repo skill holds
the *rules* (`BRAND.md`) and *manifest* (this file). Exact tokens, fonts, and binary assets stay
in Drive — fetch them via the **Google Drive connector** when producing assets.

> **Why split:** text rules are version-controlled here; heavy/binary media (fonts `.otf`, pattern
> PNGs, product photos, the source PDF) live in the brain (the media home) and would bloat git.

## To pull a local copy into this skill
If a session wants the exact tokens committed alongside the skill, copy the plain-text
`colors_and_type.css` from Drive into this folder (the binary fonts/assets stay in Drive). The
brand owner can also paste it directly. Until then, treat the Drive copy as canonical.
